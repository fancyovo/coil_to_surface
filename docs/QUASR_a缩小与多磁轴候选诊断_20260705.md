# QUASR 失败样本的 $a$ 缩小与多磁轴候选诊断

本轮针对两类失败继续检查：

1. 拓扑看起来大致正常、但 $\psi$ 的 angle 指标或磁力线漂移偏差较大的样本：固定磁轴，逐步缩小评估半径 $a$ 后重跑完整流程。
2. 拓扑明显不对，尤其局部二次型呈双曲型/saddle 的样本：回到第一步，在大范围 $(R,Z)$ 上扫描一周期闭合残差热力图，寻找其它固定点，并强制从这些候选磁轴出发重跑 $\psi$、screen 和 Boozer 面评估。

## 1. 缩小 $a$ 的结果

本轮选取了 4 个代表性 no-surface 样本，测试 $a=0.05,0.0375,0.03,0.02,0.0125,0.008$。指标如下图：

![a sweep metrics](../runs/probe_a_axis_alternatives_full/a_sweep_metrics.png)

| ID | 缩小 $a$ 后结论 | 关键现象 |
|---:|---|---|
| 27084 | 没有修复 | angle p95 从 $1.30\times 10^{-3}$ 降到约 $7.6\times 10^{-4}$ 后平台化；screen 始终 0 个 level 通过。 |
| 1407754 | 没有修复 | angle p95 随 $a$ 单调下降，但即使 $a=0.008$ 仍为 $3.89\times 10^{-3}$，fieldline drift 仍过大。 |
| 1330574 | 修复 | $a=0.05,0.0375$ 无磁面；降到 $a\le 0.03$ 后能找到 surface，$iota\approx -1.999$。 |
| 1570875 | 部分异常 | $a=0.05$ 找到很小的 $\psi=0.002$ 磁面；更小 $a$ 时 screen 通过数增加，但 Boozer LS/Newton 没有收敛到 surface。 |

判断：

- `1330574` 是明确的“默认 $a$ 太大”型失败，缩小 $a$ 可以恢复完整流程。
- `27084` 和 `1407754` 不是单纯把 $a$ 略微调小就能解决。尤其 `1407754` 在很小半径下 angle 和 drift 仍偏大，说明局部场可能本身较混沌，或当前轴/局部展开仍有问题。
- `1570875` 暴露的是另一个问题：cheap screen 与后续 Boozer 面求解之间仍有断点。它不是找不到低漂移 level，而是 screened level 的 Boozer 求解失败。

最关键的发现是：一周期闭合残差最小并不等于物理上应该选的磁轴。多个样本同时存在多个闭合固定点，其中 saddle 分支也可以有 $10^{-9}$ 量级的一周期闭合残差，但在该点附近拟合出的 $\psi$ 二次型不是正定/负定，磁面拓扑自然是错的。

因此，双曲型失败不是简单的 $\psi$ 拟合失败。对 `47722`、`51755`、`47466`、`1574935` 来说，换到另一个 elliptic 候选后，angle、screen 和 surface 都明显恢复，说明主要问题是磁轴分支选择。

## 3. 对失败来源的分类

本轮可以把失败拆成几类：

1. **$a$ 太大型**：`1330574`。小半径内磁面可恢复，默认半径已经进入坏区域。
2. **错误固定点分支型**：`47722`、`51755`、`47466`、`1574935`。这些样本存在多个一周期闭合点，单看 residual 会选到 saddle 或坏分支。
3. **局部质量仍不足型**：`27084`、`1407754`。缩小 $a$ 有帮助但不够，后续要再检查是否也有其它 axis 分支，或者是否确实局部混沌。
4. **Boozer 后处理失败型**：`1570875`、`20060`。前者 screen level 不少但 Boozer 失败；后者甚至有非常好的 elliptic axis 和 screen，但 surface 仍没出。这类问题应继续查 level 选择、surface 初值、Boozer LS/Newton 的约束与参数化。
5. **未修复 saddle 型**：`1748677`。当前扫描域和 top 候选内没找到可用 elliptic 分支，需要扩大/加密搜索或确认该位型附近确实没有可用磁面。

## 4. 对主流程的修改建议

第一步不能再只返回一个“最小一周期 residual”的磁轴。建议改成多候选流程：

1. 大范围 residual scan 找候选固定点，保留多个 residual 足够小的候选。
2. 对每个候选 trace axis。
3. 做低成本 $\psi$ fit 或至少做轴附近二次型检查。
4. 先排除 Hessian 为 saddle 的候选。
5. 对 elliptic 候选跑 cheap screen，优先选择 screen 通过数量多、最小 drift 小、angle 小的候选。
6. 只对少数最优候选进入 Boozer LS/Newton。

候选评分可以临时采用：

$$
\text{score} =
w_1 \cdot \mathbf{1}_{\text{elliptic}}
+ w_2 \cdot \text{screen\_ok\_count}
- w_3 \cdot \log_{10}(\text{angle\_p95})
- w_4 \cdot \log_{10}(\text{drift\_p95})
$$

其中 residual 只作为必要条件，而不是最终排序的主指标。

对于 $a$，建议主流程做自适应：

1. 默认从输入 $a$ 开始。
2. 若 axis 为 elliptic 但 no_surface，且 screen 全失败或 angle 偏高，则尝试 $a \leftarrow 0.75a,0.6a,0.4a,\ldots$。
3. 若缩小 $a$ 后 screen 通过但 Boozer 仍失败，应转入 Boozer/level 诊断，而不是继续无限缩小 $a$。
4. 若 $a$ 小到下界仍无 screen，标记为“局部质量不足/可能混沌”，并保留最好的 angle 与 drift 指标。

## 5. 下一步

我建议把多候选磁轴选择并入默认流程：先用 residual 找闭合点，再用 elliptic Hessian 和 cheap screen 选择物理上更合理的轴。这个修改预计能直接修复本轮多个双曲型 no-surface 样本。

同时，`20060` 和 `1570875` 应单独作为 Boozer 后处理失败样本继续查，因为它们已经不再是第一步找轴问题。
