# 计算流程

本文说明 `local_surface_evaluator` 当前默认流程。输入是一组线圈 Fourier 系数、电流和 `nfp`；输出是磁轴、局部 $\psi$ 拟合、候选磁面筛选以及 Boozer/QS 评估结果。

## 1. 输入与磁场

输入可以来自 JSON 示例，也可以直接调用 Python API。程序会把基础线圈按 `nfp` 周期复制，并按 Biot-Savart 定律计算磁场。

GPU 后端会在初始化时把每根线圈离散为小电流元，并把电流元数据放入适合批量访问的连续数组。磁力线追踪默认使用 `mixed64`：

- 电流元到磁场贡献的主要计算使用单精度，以利用 GPU 的高吞吐。
- RK4 位置推进和累积状态保留双精度语义，降低长步进漂移。
- 仍保留 `fp64` 和 `fp32` 选项用于复核和对比。

## 2. 磁轴搜索

当前默认磁轴搜索为固定点方法，而不是早期的简单遗传算法。目标是在 $\Phi=0$ 截面找到一点 $(R,Z)$，使它沿磁力线追踪一个场周期后回到自身：

$$
F(R,Z) = (R_1-R,\; Z_1-Z) \approx 0.
$$

流程为：

1. 在候选区域中建立固定点网格，默认使用 GPU 批量追踪所有网格点一周期。
2. 从闭合残差局部极小点和向量场绕数单元中提取候选点。
3. 对候选点做小批量阻尼 Newton 修正，目标仍为 $F(R,Z)=0$。
4. 用更高精度追踪复核前若干个候选。
5. 对候选点附近的 Poincare 线性化映射做低成本拓扑筛。

拓扑筛会估计局部映射的特征结构：

- `elliptic`：局部像旋转中心，优先作为磁轴。
- `hyperbolic`：局部像鞍点，通常不应作为局部磁面中心。
- `degenerate`：判定不稳定或过于退化。

默认只接受闭合残差达标且拓扑为 `elliptic` 的候选。如果存在多个椭圆候选，默认优先选 `topology_ellipse_aspect` 最接近 1 的点，即局部截面最接近圆的候选。这一步是为了避免把闭合但双曲的周期点误当作磁轴。

输出中的 `axis.best_residual` 始终保留。即使 `axis.has_axis=false`，它也代表搜索到的最小一周期闭合距离。

## 3. 局部 $\psi$ 拟合

找到磁轴后，程序在磁轴附近的局部直角坐标中拟合 $\psi$。设 $x=(R-R_{\mathrm{axis}})/a$，$z=(Z-Z_{\mathrm{axis}})/a$，其中 $a$ 是评估半径。当前形式是二元多项式乘以 $\Phi$ 方向 Fourier 模：

$$
\psi(x,z,\Phi)
= x^2 + \sum_{p,q,m} c_{pqm}\,x^p z^q T_m(n_{\mathrm{fp}}\Phi).
$$

这里固定 $x^2$ 的系数用于消除整体尺度自由度；其它二次项和高阶项由最小二乘决定，因此可以表达椭圆、倾斜椭圆和更复杂的局部截面形状。

拟合目标来自磁面条件：

$$
\mathbf{B}\cdot\nabla\psi = 0.
$$

默认采样网格为 `n_r=n_z=n_phi=80`，多项式阶数 `poly_degree=10`，环向 Fourier 阶数 `m_tor=12`。线性方程默认用 GPU 端 QR 路径求解；相比法方程，它对条件数更稳健，已经作为默认设置。

拟合质量主要看：

- `validation_angle_mean`：验证点上 $|\mathbf{B}\cdot\nabla\psi|/(|\mathbf{B}|\,|\nabla\psi|)$ 的平均值。
- `validation_angle_p95`：同一无量纲角度残差的 95 分位。
- `validation_angle_l2`：角度残差的均方根。
- `train_rms` / `validation_rms`：原始线性方程残差，用于辅助判断。

## 4. $\psi_0$ 筛选

程序不会对所有候选 $\psi_0$ 都做完整 Boozer 优化。当前先用便宜筛选：

1. 对默认 `levels` 中每个 $\psi_0$，在若干 $\Phi$ 截面上用等值曲线 Newton 找到 $\psi=\psi_0$ 的点。
2. 从 $\Phi=0$ 的曲线上取多个起点，GPU 批量追踪一个场周期。
3. 比较终点相对初始 $\psi$ 面的空间偏离。
4. 只保留半径、逃逸、漂移都合理的 $\psi_0$。

漂移指标的核心语义是“转一周期后离 $\psi$ 给出的磁面有多远”，因此比直接比较 $\Delta\psi/|\psi|$ 更接近几何误差。

这一步会输出每个 level 的：

- `radius_mean`
- `radius_max`
- `end_distance_p95`
- `rel_end_distance_p95`
- `ok`
- `reason`

## 5. 等 $\psi$ 面提取

通过筛选后，程序需要把 $\psi=\psi_0$ 的隐式面转为显式 Fourier surface。当前默认使用 GPU 端批量一维 Newton：

1. 固定一组 $(\theta,\Phi)$ 网格。
2. 沿局部射线或局部方向求解 $\psi=\psi_0$。
3. 所有网格点在 GPU kernel 中同步迭代。
4. 把得到的点云拟合为 `SurfaceXYZTensorFourier`。

这比逐点扫描和 `brentq` 快得多，并且会记录：

- `surface_extract_1d_newton_s`
- `surface_extract_coeff_build_s`
- `surface_extract_copy_in_s`
- `surface_extract_copy_out_s`

## 6. Boozer surface 与 QS 评估

对筛选出的最大若干个候选面，程序调用 Simsopt 的 Boozer surface 求解。优化目标是让给定 surface 满足 Boozer 坐标下的磁面方程和约束。当前流程包括：

1. 从 $\psi=\psi_0$ 点云拟合初始 surface。
2. 用 least-squares 步降低 Boozer residual。
3. 用 Newton 步继续收敛。
4. 收敛后计算 $\iota$、$G$、体积和 QS error。

当前实现中，前面的 $\psi$ 磁面和场线共轭构造主要用于提供接近的几何初值；最终的 $\iota$、$G$ 和 QS error 以 Boozer 求解结果为准。

输出会包含：

- `initial_boozer_residual_norm`
- `ls_residual_norm`
- `newton_residual_norm`
- `iota`
- `G`
- `volume`
- `qs_error_QA_1_0`
- `qs_error_QH_1_1`
- `qs_error_QP_0_1`

## 7. 失败语义

结构化状态分三类：

- `surface`：找到磁轴，并且至少一个候选磁面完成 Boozer/QS 评估。
- `no_axis`：没有找到满足闭合残差和拓扑筛的磁轴；仍输出 `axis.best_residual`。
- `no_surface`：磁轴存在，但 $\psi$ 拟合、$\psi_0$ 筛选或 Boozer 阶段没有产生可信磁面。

诊断时建议按顺序看：

1. `axis.best_residual` 和 `axis.topology_class`。
2. `psi.fit_info.validation_angle_*`。
3. `surface_screen.levels` 中的 `ok/reason` 和漂移。
4. `surface_candidates` 中 LS/Newton residual。

如果 `axis.best_residual` 很小但拓扑为双曲，通常说明找到的是闭合周期点而不是真正磁轴；如果 $\psi$ angle 残差很差，通常说明半径 $a$ 太大、磁轴选错或局部区域本身混沌。
