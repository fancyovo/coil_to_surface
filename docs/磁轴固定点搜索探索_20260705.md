# 磁轴第一步搜索改进探索报告

## 背景

原流程第一步使用 GA：在 $\Phi=0$ 截面撒点，追踪一个场周期后用
$\sqrt{(R_1-R_0)^2+(Z_1-Z_0)^2}$ 排序，保留 top 点并取两两中点继续迭代。
这个方法适合 GPU 批量追踪，但只利用了标量残差，容易沿着低残差窄谷收敛到错误区域，也可能在局部重建时跑到 $R<0$ 的无物理意义区域。

本次新增了独立探索脚本：

- `scripts/explore_axis_fixed_point.py`
- 输出目录示例：`runs/axis_fixed_point_*`
- 当前只作为探索脚本，没有替换主评估流程。

## 新方法

把磁轴看成一周期 Poincare 映射的固定点。定义

$$
F(R,Z)=P(R,Z)-(R,Z),
$$

其中 $P$ 是沿磁力线追踪一个场周期后的 $(R,Z)$。磁轴对应 $F(R,Z)=0$。

具体流程：

1. 自动给出一个搜索框。默认 `hybrid` 模式以线圈平均半径和线圈几何分布估计范围，并显式限制 `R >= r_floor`，默认 `r_floor=1e-4`。
2. 在搜索框内做 `grid x grid` 批量 GPU 追踪，得到每个点的向量场 $F=(\Delta R,\Delta Z)$。
3. 对网格 cell 计算 $F$ 的方向绕数。如果 cell 边界上向量方向绕原点一圈，则该 cell 内很可能有固定点。
4. 同时取若干局部残差极小值作为 fallback 候选。
5. 对候选点做批量有限差分 damped Newton。每个候选每轮需要中心点、$R\pm h$、$Z\pm h$ 和若干阻尼试探点，全部用 GPU 批量追踪。
6. 最后用 `fp64` 对 top 候选复核，判断是否低于 `tol=1e-7`。

这个方法相比 GA 的关键变化是：不只找标量残差低，而是用二维向量场的零点结构定位固定点。

## 已知好样本验证

命令：

```bash
python scripts/explore_axis_fixed_point.py \
  --case-file examples/01.json \
  --case-file examples/debug.json \
  --output-dir runs/axis_fixed_point_known_g96_v2 \
  --grid 96 \
  --include-ga
```

结果：

| 样本 | 新方法 fp64 residual | GA fp64 residual | 单样本总时间 |
| --- | ---: | ---: | ---: |
| `01` | $1.20\times 10^{-8}$ | $9.65\times 10^{-9}$ | 3.62 s |
| `debug` | $3.17\times 10^{-9}$ | $3.02\times 10^{-8}$ | 3.60 s |

两者都由 winding 候选收敛，说明固定点方法在已知好样本上可用。

## 性能瓶颈

以 `grid=48` 为建议默认时，11 个 QH 样本平均耗时：

- 网格追踪：0.245 s
- candidate/winding 检测：0.013 s
- Newton 精修：1.60 s
- fp64 复核：0.116 s
- 总计：2.04 s

目前瓶颈已经不是全局网格扫描，而是 Newton 精修。原因是脚本为了稳健，对最多 96 个候选同时做 8 轮有限差分 Newton，并且每轮还有阻尼试探。候选数量偏多时，即使每次都是 GPU 批量追踪，累计追踪次数仍然较大。

后续优化方向：

1. 减少进入 Newton 的候选数。winding cell 通常已经足够，local-min fallback 可以只在没有 winding 时启用，或把 `max_candidates` 从 96 降到 32。
2. 两阶段策略：先 `grid=48, max_candidates=32`；失败再 `grid=96, max_candidates=96`。
3. Newton 内部可以早停已经收敛的候选，当前实现为了批量简单仍会保留较多候选。
4. 若后续写入主流程，可以把有限差分和阻尼试探进一步融合为专门 GPU kernel，减少 Python 调度和多次 kernel launch。

## 建议默认配置

建议把第一步主流程从 GA 改成固定点方法，默认：

- `grid=48`
- `tol=1e-7`
- `precision=mixed64`
- `verify_precision=fp64`
- `rk4_steps=800`
- `domain_mode=hybrid`
- `r_floor=1e-4`
- `max_candidates=96` 暂时保持稳健

fallback：

1. 若 `grid=48` 无轴，改用 `grid=96` 重跑。
2. 若仍无轴，返回最优 fp64 residual 作为无轴指标，不进入后续 psi/磁面流程。
3. 对特别坏的线圈，应保留 `grid_best_residual` 和 `best residual`，用于区分“没有固定点”和“搜索没覆盖到固定点”。

## 当前判断

这个方向显著优于原 GA。它在 `01/debug` 上保持稳定，在之前 GA 失败的 11 个 QH no-axis 样本上全部救回。最重要的是它从算法上利用了 $F(R,Z)=0$ 的向量零点结构，而不是只沿标量低谷走，因此更适合崎岖 landscape。

目前建议先把它作为第一步的新默认方案接入主流程，但保留 GA 作为调试 fallback 或对照。
