# QUASR 对齐与初测

## 1. 数据格式确认

参考文件：

- [load_config.py](D:/FPC/2.4.0/bin/i386-win32/new/ML/lhls/stellarator/quasr/data/load_config.py)
- [load_config.ipynb](D:/FPC/2.4.0/bin/i386-win32/new/ML/lhls/stellarator/quasr/literature/load_config.ipynb)

确认结果：

1. 每个位型的几何文件是：
   `simsopt_serials/{ID//1000:04d}/serial{ID:07d}.json`
2. `load(...)` 返回：
   - `surfaces`: `list[SurfaceXYZTensorFourier]`
   - `coils`: 完整线圈组
3. QUASR 的对称关系已经展开在 `coils` 里，因此：
   - `len(coils) = 2 * nfp * nc_per_hp`
   - 其中只有 `nc_per_hp` 个线圈的 `curve` 类型是 `CurveXYZFourier`
   - 这些就是半周期基线圈
4. 每个基线圈：
   - `curve.order = 16`
   - `len(curve.x) = 99 = 3 * 33`
   - 顺序正好是 `[x(33), y(33), z(33)]`
5. 电流单位是 `A`，不是 `MA`

因此，QUASR 到我们当前评估器的只读适配是直接可做的。

## 8. 当前判断

初步看，当前方法对 QUASR 的 **QH 样本兼容性明显好于 QA 样本**。

这不一定说明 QA 本身更差，更可能是下面几件事之一：

1. QA 样本的局部磁面形状更不利于我们当前的 `psi0` 便宜筛选；
2. QA 样本里 `mean_iota` 较小，当前 Boozer 初值策略更容易掉进坏分支；
3. 评估半径 `a = min(0.05, 0.9 * minor_radius)` 对 QH 较合适，但对部分 QA 仍偏激进；
4. `surface` 提取或 Boozer 牛顿在 QA 上更容易遇到病态参数化。

下一步建议不是盲目扩大批量，而是先拿这批 `debug_2` 到 `debug_11` 一个个定位：

- 有些是 `no_axis`
- 有些是 `psi0` 筛选失败
- 有些是 Boozer 候选坏掉

这三类问题应分别处理。
