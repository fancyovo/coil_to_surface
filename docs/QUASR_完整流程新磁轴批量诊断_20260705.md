## 当前判断

1. 磁轴搜索改进有效。  
   本轮 QA 无 `no_axis`，QH 只有 1 个 `no_axis`，之前假轴或边缘低残差导致的失败应已大幅减少。

2. QA 的 no_surface 需要优先查两类：
   - angle 很差：先看 $\psi$ 拟合阶数、半径、训练点分布；
   - angle 不差但 drift 巨大：优先看等值线提取、$\psi_0$ 选择、截面分支和是否存在局部闭合但全周期不闭合的假面。

3. QH 的 no_surface 更像 $\psi$ 拟合质量问题。  
   QH 失败组的 angle p95 中位数是 $5.18\times 10^{-3}$，明显高于成功组的 $1.18\times 10^{-4}$。

4. Boozer 后续失败数量不多，但 QA 中有 13 个。  
   这些样本已经通过 fieldline screen，说明 $\psi$ 面本身可能不太差，下一步应检查初始面参数化、体积约束、Boozer LS/Newton 收敛路径。

## 建议下一步

优先处理顺序：

1. 对 QA 的 `screen_failed_huge_drift_despite_good_angle` 样本画 $\sqrt{\psi}$ 热力图和不同 $\Phi$ 截面，确认是不是等值线分支/选面错误。
2. 对 QH 的 `screen_failed_and_psi_angle_bad` 样本尝试提高 $\psi$ 模数或减小 `a`，看 angle 和 screen 是否同步改善。
3. 对 `boozer_failed_after_screen_ok` 样本单独诊断 Boozer residual 分解，判断是坐标初值问题还是曲面本身问题。
4. QH `ID=1301688` 单独做固定点向量场密集图，确认是否真的无轴还是搜索范围/候选筛选遗漏。
