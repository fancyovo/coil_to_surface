## 1. `no_axis`：单纯增加 GA 代数基本没用

诊断样本：

- `687078`
- `885628`
- `1100743`
- `196541`

测试：把 `max_generations` 从 `32` 扫到 `192`。

结果：

1. `687078`
   - `best_residual = 0.545914`
   - 从 `32` 到 `192` 完全不变
   - 说明不是“差一点”，而是搜索已经停在一个明显不闭合的位置

2. `885628`
   - `best_residual = 0.0126205`
   - 从 `32` 到 `192` 完全不变
   - 同样不是迭代不够，而是已经停在坏局部

3. `196541`
   - `0.00423088 -> 0.00421145`
   - 有轻微改善，但量级上仍然离 `1e-7` 很远
   - 额外代数没有实质收益

4. `1100743`
   - `best_residual = 1.00211e-07`
   - 从 `32` 到 `192` 完全不变
   - 这个样本是特殊情况：  
     搜索阶段内部的 `search_best_residual = 9.99159e-08`，其实已经略小于阈值 `1e-7`，因此搜索在第 `9` 代就停了；  
     但后续 `fp64` 复核后变成 `1.00211e-07`，被判成 `no_axis`

所以：

- 对这 4 个 `no_axis` 样本，**加代数不是主要改进方向**
- 真正值得单独处理的只有 `1100743`
  - 它不是“没收敛”，而是“搜索通过、复核略微失败”
  - 如果后面要继续救它，方向应是：
    - 复核失败后继续局部搜索，而不是直接判死
    - 或者重新审视 `1e-7` 这个阈值在 QUASR QA 上是否过硬

## 3. 热力图显示了两类完全不同的失败

### 3.1 鞍点 / 双曲型：`psi` 很准，但根本不是闭合磁面

代表图：

- [ID 54033](D:/Typora/Typ/学习/stellarator/programs/local_surface_evaluator/runs/quasr_qa_failure_diagnose_remote/id_0054033_phi_slices.png)
- [ID 820241](D:/Typora/Typ/学习/stellarator/programs/local_surface_evaluator/runs/quasr_qa_failure_diagnose_remote/id_0820241_phi_slices.png)
- [ID 636020](D:/Typora/Typ/学习/stellarator/programs/local_surface_evaluator/runs/quasr_qa_failure_diagnose_remote/id_0636020_phi_slices.png)

这些样本的共同特征是：

- 每个 `\Phi` 截面里，`psi=const` 的低值等高线是**双曲线/鞍形**
- 不是围绕磁轴的闭合椭圆
- 因此 `psi0` 便宜筛选直接失败，完全合理

也就是说，这几例的核心问题不是数值误差，而是：

- 当前拟合目标 `\mathbf{B}\cdot\nabla\psi \approx 0`
- 再加上固定 `x^2` 项

这还不足以保证 `\psi` 在轴附近是**正定二次型**

所以会出现：

- `\mathbf{B}\cdot\nabla\psi` 很小
- 但局部等值线是开放的，不像磁面

这是当前 `psi` 参数化/目标函数的结构性缺陷，不是简单把拟合精度再做高就能自动消失的。

### 3.2 椭圆型：`psi` 看起来像真的磁面，但后处理失败

代表图：

- [ID 637739](D:/Typora/Typ/学习/stellarator/programs/local_surface_evaluator/runs/quasr_qa_failure_diagnose_remote/id_0637739_phi_slices.png)

这个样本和上面那几类完全不同：

- 所有 `\Phi` 截面里低值等高线都明显闭合
- 形状是连续旋转的椭圆
- `surface_screen` 里所有候选 `psi0` 都通过了便宜筛选

但它最后还是 `no_surface`，原因是：

- 后续 3 个 Boozer candidate 都没有成功收敛
- 候选体积已经出现明显失真（正负乱飞、量级爆炸）

所以 `637739` 的问题不在 `psi` 拟合，而在：

- `surface` 提取后的参数化
- 或 Boozer LS/Newton 的初值/分支选择

它应当单列处理，不能和前面的鞍点类混在一起。

## 4. 当前最有信息量的后续方向

按优先级排序：

1. **先处理 `637739`**
   - 这是“`psi` 面像样，但 Boozer 失败”的干净样本
   - 最适合查后处理链条的问题

2. **再处理 `1100743`**
   - 它几乎通过找轴阈值
   - 最适合查“搜索通过、复核略失败”的边界行为

3. **最后再处理鞍点类样本**
   - `54033 / 55665 / 636020 / 820241 / 924851`
   - 这里需要重新想 `psi` 拟合形式或约束
   - 仅靠增加 GA 代数或提高 `psi` 拟合精度，方向不对

## 5. 结论

这批 QA 失败样本已经明确分成三类：

1. `no_axis` 且离解很远  
   - `687078`, `885628`, `196541`

2. `no_axis` 但其实只差复核一步  
   - `1100743`

3. `no_surface`
   - 其中大多数是 `psi` 形成了鞍点/开放等值线  
     `54033`, `55665`, `636020`, `820241`, `924851`
   - 只有 `637739` 是真正“`psi` 面像磁面，但后处理坏了”

因此下一步如果只挑一个样本继续查，应该优先选 `637739`。  
如果只挑一个找轴问题继续查，应该优先选 `1100743`。
