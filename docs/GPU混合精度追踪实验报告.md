# GPU 混合精度追踪实验报告

## 1. 实验目的

本轮实验以“一个 block 负责一条磁力线”的 `trace_period_blockline` 为基准，测试混合精度是否能显著加速磁力线追踪，同时保持找磁轴所需的精度。

测试了三个版本：

| 模式 | Biot-Savart 电流元到 $B$ | RK4 状态 $R,Z,\Phi$ | 说明 |
|---|---|---|---|
| `blockline` | fp64 | fp64 | 基准 |
| `blockline_mixed64` | fp32 | fp64 | 推荐候选 |
| `blockline_f32` | fp32 | fp32 | 更激进 |
| `blockline_f16state` | fp32 | fp16 量化 $R,Z$ | 验证 fp16 状态是否可用 |

实验仍使用：

```text
segments_per_coil = 256
steps = 800
lines = 256
threads_per_line = 256
CUDA_VISIBLE_DEVICES = 0
```

## 2. 速度结果

随机线 benchmark 中，`debug/raw` 的一周期追踪时间为：

| 模式 | 时间 |
|---|---:|
| fp64 blockline | 0.181353 s |
| $B$ fp32 + 状态 fp64 | 0.047349 s |
| $B$ fp32 + 状态 fp32 | 0.024825 s |
| $B$ fp32 + 状态 fp16 | 0.024978 s |

也就是说：

1. 只把 $B$ 计算改成 fp32，已经带来约 $3.8\times$ 加速。
2. 再把 RK 状态也改成 fp32，可到约 $7.3\times$ 加速。
3. fp16 状态并不比 fp32 状态更快，因为瓶颈仍然主要在 fp32 的 $B$ 计算和规约，而不是状态变量存储。

## 4. 精度判断

### $B$ fp32 + 状态 fp64

这是目前最有价值的混合精度版本。

它的特点是：

1. 电流元求和、`rsqrtf`、叉乘贡献全部在 fp32 完成。
2. RK4 的 $R,Z,\Phi,h,k_i$ 推进仍保留 double。
3. 找到的轴点再用 fp64 blockline 复核，残差仍在 $10^{-8}$ 量级。

对当前 GA 找轴任务，这个精度已经足够作为默认候选。速度相对 fp64 blockline 约加速 $3.5-4\times$。

### $B$ fp32 + 状态 fp32

这个版本速度更快，但风险明显更高。

它在自身动力系统下能收敛，但把找到的点拿 fp64 复核后：

```text
01/raw:    1.615e-07
debug/raw: 3.134e-07
```

这个量级对粗筛可以接受，但不适合作为最终磁轴残差报告。更合理的用法是：

```text
先用 fp32 快速粗筛到 1e-6 或 1e-7 附近，
再切换到 B fp32 + 状态 fp64 或全 fp64 精修。
```

### fp16 状态

fp16 状态不可用。

原因很直接：磁轴附近 $R\approx 1$，fp16 的相对精度约 $10^{-3}$，所以 $R$ 的绝对量化步长天然在 $10^{-3}$ 量级。我们的找轴残差目标是 $10^{-8}$，差了五个数量级。

实测也证实：

```text
01/raw:    不收敛，double 复核残差 1.702e-02
debug/raw: 不收敛，double 复核残差 3.885e-02
```

并且 fp16 状态几乎没有比 fp32 状态更快。因此 fp16 状态不建议继续投入。

## 5. 推荐策略

当前建议：

1. 默认追踪 kernel 使用一个 block 负责一条线，`256 threads/block`。
2. 找磁轴的主力模式使用 `blockline_mixed64`，即 $B$ fp32、RK 状态 fp64。
3. 若需要更激进加速，可以先用 `blockline_f32` 做粗筛，再用 `blockline_mixed64` 或 fp64 做精修和最终残差复核。
4. 不使用 fp16 状态。

一个比较稳妥的找轴流程是：

```text
阶段 1: blockline_f32，大范围 GA 粗筛，目标残差 1e-6 到 1e-7
阶段 2: blockline_mixed64，继续 GA 或局部细化，目标残差 1e-8
阶段 3: fp64 blockline，只对最终候选做一次复核并报告残差
```

这样能利用 5090 的 fp32 算力优势，同时避免最终指标被低精度动力系统污染。
